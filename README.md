# UPI Fintech Market Dashboard 📊

## Problem Statement
Banks and fintechs lack a consolidated view of UPI growth trends, 
app concentration, and geographic gaps — making strategic decisions harder.

## What I Built
A 3-page Power BI dashboard analyzing 5 years of NPCI UPI transaction 
data (2020–2025) across 114 months.

## Dashboard Pages
- **Page 1:** KPI Cards + Monthly Volume & Value Trend (2020–2025)
- **Page 2:** App Market Share (Donut) + State-wise Distribution (Bar Chart)
- **Page 3:** Analyst Insight Memo — 3 findings + 1 recommendation

## Key Insights
1. Volume grew 32% YoY in FY25 but value only 21% — ticket size falling
2. P2M now dominates — 86% of merchant payments below ₹500
3. Top 3 states = 20% of transactions — Tier-2/3 is the next frontier

## Recommendation
Banks should launch UPI products targeting Tier-2 merchants — 
volume exists but high-value use cases are underpenetrated.

## Tools Used
- Microsoft Excel — data cleaning + calculated columns
- Power BI Desktop — dashboard + visualizations
- Data Source: NPCI official statistics (via Kaggle)
